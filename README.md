Smart Water Resource Management Information System for Vavuniya
📌 Project Overview

The Smart Water Resource Management Information System for Vavuniya is a proposed information system designed to support better water resource management, improve access to water-related information, and provide a platform for reporting and monitoring water-related issues.

The project was developed as part of my Bachelor of Business Information Systems (BIS) research project, focusing on the water-management challenges experienced by communities in Salalihinigama and Nandimithragama, Vavuniya.

The system concept is based on findings collected through a mixed-method research approach, combining questionnaire data and stakeholder interviews.

🎯 Project Objectives
Identify key water-management challenges faced by local communities.
Understand community requirements for a digital water-management system.
Provide accessible water-quality and water-availability information.
Support reporting of water-related problems.
Provide information about water supply schedules and maintenance.
Support decision-making using data visualization and reporting.
🔍 Research Approach

A Convergent Mixed-Methods research design was used.

Quantitative Data
61 valid questionnaire responses
Data collected from households in Salalihinigama and Nandimithragama
Questionnaire administered using Google Forms
Data analysed using:
Microsoft Excel
SPSS
Power BI
Qualitative Data
3 semi-structured stakeholder interviews
Interviews focused on water management, water supply, and water-quality-related issues.
Thematic analysis was used to identify key themes.
📊 Key Findings

Some of the major issues identified through the research included:

96.7% reported experiencing dry-season water shortages.
85.2% identified poor drinking-water quality as a concern.
63.9% reported high costs for obtaining clean water.
60.7% reported difficulties related to travelling long distances to collect water.
82.0% perceived health-related effects associated with water issues.
88.5% wanted access to water-quality information.

These findings were used to identify system requirements and design the proposed information system.

💡 Proposed System Features

The proposed system includes the following key features:

👤 User Login

Secure access for system users.

🏠 Dashboard

Provides an overview of important water-related information.

💧 Water Quality

Displays information related to water quality and availability.

📅 Supply Schedule

Provides information about planned water supply schedules.

🚨 Report a Problem

Allows users to report water-related issues.

🔔 Notifications

Provides updates regarding water supply, maintenance, and reported issues.

📊 Data Dashboard

Power BI visualisations can be used to support analysis and decision-making.

🖥️ System Design

The system concept was designed using Figma and includes interface concepts such as:

Login
Home / Dashboard
Water Quality
Supply Schedule
Report Problem
Notifications / Status

The design focuses on providing a simple and accessible interface for community users and relevant stakeholders.
